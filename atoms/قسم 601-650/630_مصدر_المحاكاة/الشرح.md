# الذرّة 630 — مصدر المحاكاة (إعادة التشغيل)

> **البناء ٢ (X.md):** «نفس كود الاستراتيجيّة يعمل في المحاكاة وفي الحيّ بلا تعديل سطر.»
> **مبدأ من NautilusTrader — النسخ المبدأ وحده، لا الكود.**

## ما تفعله
تقرأ التِكّات المسجّلة من `var/store/market_data.db` وتنشرها كأحداث `feed.replay.tick` بنفس شكل حمولة `622` (تغذية سي تريدر) بالضبط — حتى لا تفرّق بقية المنظومة بين الحيّ والمحاكاة.

## ما لا تفعله
- لا تلمس النواة ولا أي ذرّة أخرى
- لا تنشر أوامر ولا تتصل وسيطًا
- لا تكتب في مخازن الإنتاج (تفعيلها يدويّ `startup_mode: manual`)

## الطريق
```
الحيّ:     622 → feed.ctrader.tick → 613 → 112 → الأقسام → القرار
المحاكاة:  630 → feed.replay.tick  → 613 → 112 → الأقسام → القرار
                ▲
                نفس المسار بالضبط — ذرّة المصدر وحدها تختلف
```

## الإعدادات
| المفتاح | المعنى | الافتراضي |
|---|---|---|
| `db_path` | مسار قاعدة التِكّات | `var/store/market_data.db` |
| `symbol` | رمز واحد أو فارغ = الكل | `""` |
| `speed` | سرعة الإعادة (0 = فوري، 1 = زمن حقيقي) | `1.0` |
| `batch_size` | عدد التِكّات بالدفعة الواحدة | `100` |
| `start_at` / `end_at` | نطاق زمني (epoch) | `null` |
| `loop` | تكرار عند النهاية (1 = نعم) | `0` |

## التنشيط
`startup_mode: manual` — تُشغَّل بأمر صريح من المالك أو بوابة 901، **لا تعمل تلقائيًّا**.
