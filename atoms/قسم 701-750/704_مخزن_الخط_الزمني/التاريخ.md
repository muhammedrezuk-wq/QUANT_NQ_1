## 5.1.0 — 2026-08-27 (found during a full 304-atom audit, not assumed)

**`manifest.yaml`'s declarative `subscribes:` list and `config.watch_events`
are two separately hand-maintained lists in the same file -- nothing kept
them in sync, and they had drifted in both directions:**
- **4 names declared subscribed but never actually watched** at runtime
  (`risk.account.state`, `risk.audit.state`, `execution.reconcile.state`,
  `reference.health.state`): dead declarations. Only `config.watch_events`
  drives the real `context.subscribe(...)` calls in `initialize()` -- an
  operator debugging an incident and trusting the manifest would expect
  these events in the timeline and find nothing, silently.
- **6 names actually subscribed via `watch_events` but invisible to
  `subscribes:`** (`platform.position.appeared`, `market_data.validation_failed`,
  `market_data.quality_alert`, `structure.validation_failed`,
  `liquidity.validation_failed`, `market_data.calendar_window`): recorded
  correctly at runtime, but any tooling reading only the manifest's
  declarative list (dependency graphs, impact analysis of a rename/removal
  elsewhere in the project) would never know this atom depends on them.

**Fix:** `subscribes:` now lists exactly `config.watch_events` plus
`SYS_DAY`/`SYS_SECOND` (the two events subscribed unconditionally in code,
outside `watch_events`) -- verified equal, not just eyeballed.

**New regression test** `test_manifest_subscribes_matches_runtime_watch_events`
reads `manifest.yaml` directly (via `yaml.safe_load`, matching
`governance/scripts/validate_atoms.py`'s own convention) and asserts the
two sets are identical, reporting exactly which names are on which side
of a mismatch. Verified empirically before trusting it: reverted the real
manifest back to the old drifted list, confirmed the test fails and
reports precisely the same 4-and-6 split documented above, then restored
the fix. This test now guards against the exact same drift recurring
silently in the future. 5/5 tests passing, validator 0 violations.
